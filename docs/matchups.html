Batter clusters vs pitcher clusters

Do similar batters perform alike against the same pitcher cluster?

Each dot is one batter against one pitcher cluster. It shows how that batter did compared with expectation (y) against how the batters most similar to them did against the same cluster (x, weighted by similarity, leaving the batter out). Expectation already accounts for the batter's overall talent and each pitcher's overall quality, so what's left is the matchup effect. If similar batters really react alike, the dots trend upward and r beats the random-batter baseline.
